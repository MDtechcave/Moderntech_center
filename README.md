# HR Management System - ModernTech Employee Center

A comprehensive HR Management System built with Vue 3 and Vite. This application streamlines human resource operations including employee management, performance tracking, recruitment, and reporting.

## 📋 Overview

The HR Management System is designed to provide a centralized platform for managing all HR-related activities in an organization. It enables HR professionals to efficiently handle employee data, track performance metrics, manage recruitment processes, and generate valuable insights through reporting tools.

## ✨ Key Features

- **Employee Management:** Add, update, and manage employee records with detailed information
- **Performance Tracking:** Monitor and evaluate employee performance metrics over time
- **Recruitment Management:** Handle job postings, applications, and candidate evaluations
- **Attendance Tracking:** Keep accurate records of employee attendance and leaves
- **Payroll Management:** Streamline salary and compensation processes
- **Reporting & Analytics:** Generate comprehensive HR reports and insights
- **Role-Based Access Control:** Secure user authentication with different permission levels (Admin, HR Manager, Employee)
- **Document Management:** Store and manage HR-related documents and certificates

## 🛠️ Tech Stack

- **Frontend Framework:** Vue 3
- **Build Tool:** Vite
- **Language:** JavaScript/Vue
- **IDE Recommended:** VS Code with Vue (Official) extension
- **Browser DevTools:** Vue.js devtools

## 📦 Project Setup

### Prerequisites
- Node.js (v14 or higher)
- npm or yarn package manager

### Installation

```sh
# Clone the repository
git clone https://github.com/MDtechcave/Moderntech_center.git

# Navigate to project directory
cd Moderntech_center

# Install dependencies
npm install
```

## 🚀 Development

### Compile and Hot-Reload for Development

```sh
npm run dev
```

The application will be available at `http://localhost:5173`

### Compile and Minify for Production

```sh
npm run build
```

See [Vite Configuration Reference](https://vite.dev/config/) for more details.
